# ForcedBreak

一个 Windows 上的**强制休息提醒工具**。

久坐工作时，普通的番茄钟提醒太容易被"再干五分钟"忽略掉。ForcedBreak 到点后会在**所有显示器**上
弹出全屏黑色遮罩并屏蔽切换类快捷键，让你没法轻易划走——要么老老实实等倒计时结束，
要么输入密码提前解锁。

程序没有主窗口，常驻系统托盘，所有操作都从托盘右键菜单发起。

## 功能

### 全屏遮罩，覆盖每一块屏幕

休息开始时，每块显示器上都会出现一块纯黑遮罩，居中显示提醒文案与 `mm:ss` 倒计时。
休息期间新插上的显示器会被立刻补上遮罩，不会留下"另一块屏还能用"的缺口。

遮罩窗口不出现在任务栏和 Alt+Tab 列表中，并每 500ms 主动抢回焦点，避免被其他窗口盖住。

### 拦截切换类快捷键

休息期间会安装 Windows 低级键盘钩子，拦截这些逃逸手段：

| 快捷键 | 说明 |
|---|---|
| `Alt + Tab` | 切换窗口 |
| `Win` 键 | 连带拦下 `Win + D`、`Win + E` 等一整族快捷键 |
| `Alt + F4` | 关闭窗口 |
| `Alt + Esc` / `Ctrl + Esc` | 切换窗口 / 打开开始菜单 |

> **说明**：`Ctrl + Alt + Del` 属于 Windows 安全桌面，任何应用程序都无法拦截，这是系统设计使然。
> ForcedBreak 的定位是"帮你克服惰性"，而不是不可绕过的家长控制。

普通打字输入不受影响；若钩子安装失败（例如被安全软件拦下），程序会降级继续工作，遮罩照常显示。

### 密码解锁

遮罩右下角有一个低调的「跳过」按钮，点开后输入解锁密码即可提前结束休息。
密码错误时输入框会抖动提示。解锁后本次休息作废，重新开始一个完整的工作周期。

密码默认为 `123456`，请在设置中及时修改。。

> 解锁密码只用于提前结束休息；退出程序和打开设置窗口都不需要密码。

### 自定义提醒文案（富文本）

提醒文案支持富文本编辑：加粗、斜体、下划线、字号、文字颜色，随时可以一键恢复默认文案。

默认文案是大字号的「该休息了」加一行小字「起身活动一下眼睛」，你也可以换成自己的座右铭、
待办清单，或者任何能把你从屏幕前拽起来的话。

### 托盘菜单

![托盘菜单](asserts/menus.png)

| 菜单项 | 作用 |
|---|---|
| 状态行 | 只读，显示「距下次休息 mm:ss」/「休息剩余 mm:ss」/「未启用」 |
| 启用强制休息 | 总开关。**每次启动程序默认关闭**，需手动开启；休息进行中不允许关闭（否则就成了绕过密码的后门） |
| 立即休息 | 跳过剩余工作时间，马上进入休息 |
| 重置计时 | 丢弃已累计的工作时间，从头开始一个完整工作周期 |
| 休息时间设置… | 打开设置窗口的「休息时间」页 |
| 显示文案设置… | 打开设置窗口的「显示文案」页 |
| 解锁密码设置… | 打开设置窗口的「解锁密码」页 |
| 开机自启动 | 勾选后写入 `HKCU\...\Run`，随 Windows 启动 |
| 退出 | 退出程序 |

鼠标悬停在托盘图标上也能直接看到当前剩余时间。

### 时长设置

| 项目 | 范围 | 默认值 |
|---|---|---|
| 工作时长 | 1 – 480 分钟 | 45 分钟 |
| 休息时长 | 5 – 3600 秒 | 300 秒（5 分钟） |

修改工作时长会立即按新时长重新计算当前周期的剩余时间。

## 系统要求

Windows 10 / 11（64 位）。
